# Case File #002 — The Change Healthcare Ransomware Attack

## Overview

This project analyzes the 2024 Change Healthcare ransomware attack from a healthcare cybersecurity perspective.

The case study examines the incident, attack method, incident response, business impact, healthcare impact, and security-governance implications.

## Skills Demonstrated

- Healthcare Cybersecurity
- Business Impact Analysis
- Incident Response
- Security Governance
- Cybersecurity Risk Analysis
- Business Continuity

## Project Deliverables

### 1. Case Study

A structured analysis of the Change Healthcare ransomware incident.

### 2. Healthcare Security Recommendations

Actionable recommendations designed to help healthcare organizations improve resilience against similar cyber incidents.

### 3. LinkedIn Carousel

A concise visual communication of the incident, its impact, and the key cybersecurity lessons.

## Key Areas Analyzed

- Ransomware
- Identity and Access Management
- Multifactor Authentication
- Network Segmentation
- Incident Response
- Business Continuity
- Third-Party Risk
- Patient Privacy
- Security Governance

## Sources

The analysis is based primarily on publicly available information from the U.S. Department of Health and Human Services, UnitedHealth Group, and the U.S. Senate Finance Committee.

## Disclaimer

This project is an educational cybersecurity case study based on publicly available information. It does not represent an internal investigation of Change Healthcare.
